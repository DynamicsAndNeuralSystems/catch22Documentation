# Citing catch22

If you use _**catch22**_ in a scientific publication, please read and cite this open-access article:

{% hint style="success" %}
Lubba et al. [_catch22_: CAnonical Time-series CHaracteristics](https://doi.org/10.1007/s10618-019-00647-x), _Data Min Knowl Disc_ **33**, 1821 (2019).
{% endhint %}

{% hint style="info" %}
**Note**: When presenting results using _catch22_, please identify the **version used** to allow clear reproduction of your results, because feature values can change between versions.
For example, _catch22_ v1.0 changed most feature values to match _hctsa_ v3.0.0 exactly (see the [feature descriptions](../information-about-catch22/feature-descriptions/)).
If you use a language package (e.g., _pycatch22_), report both its version and the version of _catch22_ it computes.
{% endhint %}

***

### BibTeX Entry (paper):

```
@article{Lubba2019:Catch22CAnonicalTimeseries,
	title = {catch22: {CAnonical} {Time}-series {CHaracteristics}},
	volume = {33},
	issn = {1573-756X},
	url = {https://doi.org/10.1007/s10618-019-00647-x},
	doi = {10.1007/s10618-019-00647-x},
	number = {6},
	journal = {Data Mining and Knowledge Discovery},
	author = {Lubba, Carl H. and Sethi, Sarab S. and Knaute, Philip and Schultz, Simon R. and Fulcher, Ben D. and Jones, Nick S.},
	month = nov,
	year = {2019},
	pages = {1821--1852},
}
```

***

### Citing the software version

In addition to the paper, you can cite the version of the _catch22_ software that you used through its archived release on Zenodo:

* **A specific version** (recommended for reproducibility): _catch22_ v1.0.1 is [10.5281/zenodo.23486629](https://doi.org/10.5281/zenodo.23486629), and v1.0.0 is [10.5281/zenodo.23485546](https://doi.org/10.5281/zenodo.23485546) (v1.0.0 and v1.0.1 give identical feature values).
* **All versions**: the concept DOI [10.5281/zenodo.4431165](https://doi.org/10.5281/zenodo.4431165) always resolves to the latest release.

Each Zenodo record provides a citation (including BibTeX) for that version.
