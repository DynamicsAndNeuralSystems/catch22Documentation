# Citing catch22

If you use _**catch22**_ in a scientific publication, please read and cite this open-access article:

{% hint style="success" %}
Lubba et al. [_catch22_: CAnonical Time-series CHaracteristics](https://doi.org/10.1007/s10618-019-00647-x), _Data Min Knowl Disc_ **33**, 1821 (2019).
{% endhint %}

{% hint style="info" %}
**Note**: When presenting results using _catch22_, please identify the **version used** to allow clear reproduction of your results. For example, `CO_f1ecac` was altered from an integer-valued output to a linearly interpolated real-valued output from `v0.3`.&#x20;
{% endhint %}

***
